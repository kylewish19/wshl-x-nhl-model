# Reusable postgame grading (2026-11-26)

Use grade-core.yml with explicit target_date, core_run_id, optional research_run_id, mode=live. This is a grading request, not a prediction run. All supplied locked games must be final. The source run must be successful on main with expected workflow and artifact name. Verify independent core upload cutoff, manifest hashes, original candidate identities/probabilities/prices, and (if provided) research source artifact ID, cutoff and source hashes. Never use a replay, late lock or a different slate's research. Original odds only. The November 25 review fallback is a verification exercise using original clean artifacts and finalized box scores, not a new clean grade.

The runner uses existing NHL boxscore parsers. Raw outcome parquet files are private working files, not uploaded. The existing unified research grader handles totals, goalie versions, spread comparisons, goalie consensus and ATG basis subgroups where present in the frozen source. Official grading covers the three existing cards, current-season ATG blend Top10, and the frozen ATG consensus card. No new picks or probabilities. Settlement uses final score (including official shootout score for team markets), actual player goals, saves for verified starters; nonstarter/DNP void under existing paper rules. Whole-line pushes have zero return and are excluded from settled accuracy metrics. Any actual sportsbook-specific exceptions require explicit review. Research comparators still use their original supported half-lines.

The workflow uploads derived official and research grade outputs and a hash-bound grading manifest. New dates produce proposed season summary and research ledgers; review and commit the dated grade CSVs and approved ledger files, together with lessons/handoff. No automatic writes to main. Duplicate dates fail; November 25 review mode compares original results but does not create a new proposed season record. Cumulative Brier uses previous stored rounded aggregates weighted by settled rows, preserving existing convention. Top10 paper profit may be computed diagnostically but is not added to the canonical season summary. If research unavailable, explicitly mark NOT_SUPPLIED; official-only grading does not manufacture research records. Later research-only grading remains available through its own workflow.

Live grading still needs an actual newly locked slate and human review before canonical publication. Existing historical archive retention and advanced-data rights unresolved. No sportsbook access or wagers.
